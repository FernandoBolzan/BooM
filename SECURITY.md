# Security policy

BooM is a local system information and maintenance tool. Please do not include
personal hardware inventories, usernames, process command lines or other private
host data in public bug reports.

To report a security issue, use GitHub's private vulnerability reporting for
this repository when available. If it is unavailable, open a minimal issue asking
for a private contact channel; do not publish exploit details before a fix is
available.

Supported release: the latest published version. Security fixes are tracked in
the changelog and released as a new version.
